# ⚡ Ultimate Crisp Pixel Converter

A lightweight, browser-based web application designed to convert standard images into clean, retro-style pixel art instantly. Built as a fast and privacy-focused MVP using vanilla HTML5, CSS, and JavaScript.

## 🚀 Features

* **Instant Pixelation:** Upload any standard image (`.png`, `.jpg`, `.jpeg`) and downsample it into crisp pixel art.
* **Adjustable Scale Factors:** Choose between 2x, 4x, and 8x scale options to achieve the desired retro look.
* **Client-Side Processing:** All image conversions happen securely within your browser—no files are uploaded or stored on external servers.
* **One-Click Download:** Export and save your converted pixel art as a high-quality PNG instantly.
* **Retro Arcade UI:** Designed with a sleek, dark-mode 8-bit aesthetic.

## 🛠️ Local Development & Testing

If you want to run or test this project locally on your machine, follow these steps:

1. Clone the repository:
   ```bash
   git clone [https://github.com/handlevault-official/crisp-pixel-converter.git](https://github.com/handlevault-official/crisp-pixel-converter.git)
   
 2.  Navigate to the project directory:
   cd crisp-pixel-converter

 3.  Run a local HTTP server (using Python):
     python3 -m http.server 8000
     
 5. Open your browser and go to:
    http://localhost:8000
